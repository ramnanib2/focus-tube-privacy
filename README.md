# Focus Tube Privacy Policy

Public privacy policy for the Focus Tube browser extension.

## Chrome Web Store privacy policy URL

https://ramnanib2.github.io/focus-tube-privacy/privacy.html

The same policy is available at https://ramnanib2.github.io/focus-tube-privacy/.

## Hosting

GitHub Pages serves the `main` branch at the repository root over HTTPS. `.nojekyll` keeps the site as static HTML. The policy files contain no scripts, remote fonts, or analytics.

## Updating the policy

Update both `privacy.html` and `index.html` with the same policy. Keep the policy bundled in the extension and its store disclosures consistent with the hosted version. Commits to `main` redeploy the site automatically.

This repository contains only public policy files and this README. The extension source, test data, browser profiles, and publishing screenshots are not hosted here.
